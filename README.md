# SMS-Based Expense Tracker 📊

An Android application that automatically reads bank and UPI SMS 
messages and tracks expenses — no manual entry required.

## Features
- 🔐 Firebase Phone OTP Authentication
- 📨 Auto SMS scanning — reads bank & UPI transactions
- 📊 Dashboard with date range filter
- 📈 Pie chart + Bar chart analytics
- 🗓️ Spending heatmap calendar
- 🤖 AI financial advisor & health score
- 💰 Monthly budget with alerts
- 📄 CSV export to Downloads folder
- 🔄 Recurring payment detector

## Tech Stack
- Kotlin + Jetpack Compose
- Firebase Authentication
- Room Database (SQLite)
- MPAndroidChart
- Android ContentResolver (SMS)

## Setup
1. Clone the repository
2. Add google-services.json to app/ folder (contact developer)
3. Open in Android Studio
4. Run on Android device
